# Exercise Demo GIFs — Attribution

Exercise demonstration animations bundled with FixPose (`assets/demo/*.gif`, 36 files).

- **Source:** "Fitness Exercises with Animations" dataset (Edoardo Badolez /
  `edoardoba` on Kaggle) — https://www.kaggle.com/datasets/edoardoba/fitness-exercises-with-animations
- **Hosting:** mirrored by the MIT-licensed repository
  https://github.com/omercotkd/exercises-gifs (backup host for the original
  dataset URLs)
- **Mapping:** each `<exercise-id>.gif` filename matches the `id` in
  `assets/data/exercises.json`. Exercises without a match (`v-up`,
  `warrior-flow`, `downward-dog`, `cobra-stretch`) render the form-guide
  panel instead.
