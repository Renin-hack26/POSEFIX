Build label, honestly

This is a debug build

The published file is compiled with the Flutter debug configuration and signed with the Android debug keystore — the same output you get from flutter build apk --debug. It is meant for direct install, demoing and testing, not for a store release.

What that means for you

  • Sideloading only — it is not published on Google Play and has no automatic updates.
  • Signed with the debug key, so it cannot be upgraded in place by a differently signed release build.
  • Debug builds are larger and start slower than an equivalent --release build.
  • Android may show a Play Protect or “unknown app” prompt — that is expected for any APK installed outside the Play Store.

Install

Sideload it in four steps

Android blocks APKs from outside the Play Store until you allow it, once, for the app you download with.

  1. Download the APK

    Tap any Download APK button on this site and save the file. A browser warning that “this type of file can harm your device” is Android’s standard notice for every APK from outside the Play Store — check the checksum above if you want certainty about the file you have.

  2. Allow your browser to install unknown apps

    Settings → Apps → Special app access → Install unknown apps → pick the browser or file manager you downloaded with (Chrome, Files, etc.) → turn on Allow from this source. The same screen also appears as a one-tap prompt when you first open the file.

  3. Open the downloaded file

    Open it from the browser’s downloads list or your notification shade / file manager. Android shows the package name and asks whether you want to install an update to an existing app — choose Install.

  4. Install, then grant the camera

    When installation finishes, tap Open. FixPose asks for camera access (needed for pose detection) and notification permission (for workout reminders). Denying the camera means the coaching session cannot run.

To install a newer build later: download it and install over the existing app. If Android reports a signature conflict, uninstall the old version first — your local workout history lives in the app’s database and would be removed with it, so export from Settings → Export workouts first.
